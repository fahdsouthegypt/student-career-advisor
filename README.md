# 🎓 AI Career Advisor (Gemini Powered)

وكيل ذكاء اصطناعي تفاعلي يعتمد على **Google Gemini 1.5 Flash API** لتقديم استشارات مهنية وتحليل السيرة الذاتية للطلاب والخريجين الجدد.

## 🌟 المميزات الرئيسية
- **إرشاد مهني متكامل:** تقديم استشارات مخصصة لمتطلبات سوق العمل.
- **تحليل السيرة الذاتية:** فحص ملفات الـ CV وتحديد نقاط القوة والتحسين.
- **دعم تقنيات Google AI:** الاعتماد على نماذج Gemini فائقة السرعة والدقة.
