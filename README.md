## 🎯 سير العمل (Workflow)
1. **استقبال الاستفسار:** (كتابة الـ CV، المقابلات الشخصية، اختيار التخصص).
2. **التحليل والرد:** تقديم نصائح إرشادية فورية وعملية موجهة للشباب.
3. **التوجيه:** إعطاء خطوات تطبيقية واضحة للبدء فوراً.
